# METRIC-GRADING · 本癌种启用哪几项分级，为什么（本轮：**不启用**）

> 家族 23 号给了"指标分析与卡片提醒原则"，乳腺癌用 CTCAE v5.0 做化疗毒性分级对照。
> 本文件回答一个问题：**FerroPal 为什么一项分级都不启用**，以及不启用时提醒怎么做。

## 一、结论

**本轮启用 0 项自动分级。** 界面不出现任何"级别 / 严重度 / 是否达标"徽章。

## 二、逐项判断（不是偷懒，是逐条否掉的）

| 候选分级 | 家族用法 | 为什么在 TDT 不适用 | 替代做法 |
| --- | --- | --- | --- |
| CTCAE v5.0 血液学分级（Hb/中性粒/血小板） | 化疗毒性对照 | TDT 的 Hb 低是**疾病本身与输血节律**决定的，不是治疗毒性；按 CTCAE 分级会把"该输血了"误读成"3 级贫血" | 只记输血前 Hb 数值 + 输血间隔 |
| 铁蛋白阈值分级 | — | 铁蛋白受炎症、肝病、检测方法影响；各中心参考区间不同；且**分级即判读** | 趋势图 + 报告原文 + 参考区间（照抄化验单） |
| 心铁/肝铁 T2\* 分级（>20 / 10–20 / <10 ms） | — | T2\* 阈值随 MRI 序列与中心而异，且这是**放射科判读**；工作台给分级等于替代医生 | 存 `t2star_ms` 数值 + 报告原文；不画阈值线 |
| 生长发育 Z 分数分级（矮小/正常） | — | "是否矮小"是临床诊断；工作台只应显示**百分位与参考标准版本** | 百分位曲线 + "医生上次怎么说"原文 |
| 去铁依从性评分 | — | 依从性是**评价患者**，不是帮患者；且漏记 ≠ 未做 | 打卡日历（三态：已做/未做/未记） |

## 三、不启用分级时，提醒怎么做（23 号"提醒"部分的裁剪版）

提醒只允许三种形态，且都不带判定语气：

1. **节律提醒**（事实型）：`距上次输血 18 天`、`铁蛋白上次记录在 2026-07-02（115 天前）`。
2. **逾期提醒**（可解释型）：`心铁 T2* 上次记录 2025-11-03，超过 12 个月未记录`——**只说"未记录"，不说"该查了"**。
   是否该查由 `screening_item.planned_date`（医嘱原文）决定，不由工作台决定。
3. **缺口提醒**（诚实型）：`这份报告只记了数值，没有参考区间` → 引导补录，不猜区间。

禁止：`偏高` / `异常` / `建议复查` / `风险升高` / `依从性差` / 任何颜色编码的"红黄绿"健康状态。

## 五、什么时候可以重开这个议题

拿到**带页码的中文指南**、且指南里确有"分级"表述、且能明确"这是给医生看的判读"时，
才可以讨论启用**双标准并列**（23 号 §双标准并列）。在此之前，**不启用**。
