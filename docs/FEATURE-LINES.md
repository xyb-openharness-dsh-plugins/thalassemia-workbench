# FEATURE-LINES · 每条功能线挂一句患者原话（证据状态逐条标）

> 这是「患者视角红线」的落地件：**13 条一级功能线，每条一个原话位**，界面里对应页顶部 `.voice` 区块逐字渲染本表。
> 证据状态：`public` = 公开报道中家长/患者的**直接引语**（附编号与来源，见 `research/patient-voices.md`）；
> `hypothesis` = 疾病轴推导的**假设句**（界面必须显示「假设句 · 未经访谈核实」）。
> **本轮一手访谈 = 0 条**；`public` 也不得表述为"我们访谈了 N 位家长"。

## 与验收的接线

- G2 独立评审：逐页对照本表，页面上原话与状态徽章必须**逐字一致**；`public` 缺来源 = P1，`hypothesis` 冒充引语 = **P0**。
- `scripts/check-hvt.mjs`：每个一级页恰好 1 处 `.voice`（防止悄悄删掉假设）。
- 下一轮访谈后：把对应行的 `hypothesis` 改为 `interview` 并写访谈编号，界面徽章同步换字。
