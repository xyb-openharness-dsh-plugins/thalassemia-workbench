## 一、场景路径表（六要素齐全，缺一记"未写"）

入口文案与 `src/pages.json` 的 `label`/`subs` 逐字一致（IP3）。

| ID | 场景 | 入口（看板哪块） | AI 路径（默认） | 手工路径（收敛） | 产物 | 回首页 | 失败恢复 |
| --- | --- | --- | --- | --- | --- | --- | --- |
| S01 | 记录一次输血 | 看板卡「距上次输血 18 天 · 记录这次」 | 拍输血记录单 → 候选（日期/Hb/量/反应）→ 逐项核对 | 「输血本 › 输血记录」卡片右上「⋯ 更多 › 手工补一条」（5 字段：日期、输血前 Hb、量、制品、反应） | 输血记录 +1；看板倒计时重置 | 完成后 Toast 内「回到看板」 | 识别失败 → 原文留资料库，候选可重试；写库失败 → 整体回滚提示"这次没记上" |
| S02 | 看输血间隔趋势 | 看板卡「近 6 次间隔」 | 对话"我上个月输血是不是太密了" → AI 只取记录、不改记录 | 「输血本 › 周期与间隔」只读 | 一张间隔折线（含带宽说明） | 二级页返回 | 少于 2 条记录 → 空态"记满两次才能算间隔" |
| S03 | 记一次铁蛋白 | 看板卡「铁蛋白 115 天未记录」 | 拍化验单 → 候选（日期/数值/单位/参考区间/化验室） | 「铁负荷与排铁 › 铁蛋白趋势」→「⋯ 更多 › 手工补一条」（4 字段） | 铁蛋白点 +1 | Toast「回到看板」 | 单位缺失 → 标「单位待确认」，不入趋势 |
| S04 | 记一次方案变更 | 看板卡「去铁方案」 | 对话"这周换成地拉罗司了，因为胃肠反应" → 候选方案行 | 「铁负荷与排铁 › 去铁方案」→「⋯ 更多 › 记一次变更」（5 字段） | 新方案行（旧行保留） | Toast | 用户改主意 → 「改这一条」新增修正版本，不删旧 |
| S05 | 量一次身高体重 | 看板卡「生长发育」 | 拍生长记录或对话"今天 118cm / 21kg" → 候选 | 「生长发育 › 身高体重百分位」→「⋯ 更多 › 手工补一条」（3 字段：日期、身高、体重） | 生长点 +1；百分位自动重算 | Toast | 缺生日 → 提示"先在病情档案补出生日期" |
| S06 | 勾一次筛查完成 | 看板卡「逾期未记录：心铁 T2\*」 | 拍报告 → 候选（项目/日期/结果原文） | 「筛查日历 › 年度清单」条目右「已做 · 记一下」（3 字段） | 筛查项状态变「已做」+ 结果原文 | Toast | 报告未出 → 三态选「未出报告」，不加结论 |
| S07 | 整理一次复诊材料 | 看板卡「下周三复诊 · 准备材料」 | 对话"帮我整理这三个月的变化" → AI 产出**候选清单**（可增删） | 「就诊准备 › 就诊问题清单」逐条勾选/手加（1 字段即可） | 导出 Markdown（含每条来源页与日期） | 导出完成 Toast + 回到看板 | AI 不可用 → 面板降级为手动勾选列表，功能不中断 |
| S08 | 记一次费用 | 看板卡「本月自费」 | 拍发票 → 候选（日期/类别/金额/是否医保） | 「费用与血源 › 输血费用」→「⋯ 更多 › 记一笔」（4 字段） | 费用行 +1；按月分项聚合 | Toast | 金额为 0 或空 → 存 `null` 不存 0，不参与求和 |
| S09 | 记一次抗体/配血 | 输血本 › 抗体与配血 | 拍配血单 → 候选（日期/抗体名称原文/交叉配血结果原文） | 同页「⋯ 更多 › 手工补一条」（4 字段） | 抗体记录 +1 | 二级页返回 | 报告只有"未见异常"字样 → 存原文，不转成"阴性"判定 |

| S11 | 在趋势里看某一天发生了什么 | 病情一图秀 › 数值曲线 | —（图表不出 AI 通道，改走对话解读其**记录**） | 点数据点 → 整页视图显示当天所有记录 | 当天记录详情（只读） | 关闭 → 回原滚动位置 | 当天无记录 → 空态"这天没有记录" |
| S12 | 补一份外院报告 | 资料库 › 资料库 | 拖入 PDF/照片 → 候选（kind/日期/医院） | 「⋯ 更多 › 手工登记一份」（3 字段，只登记不解析） | 文档 +1，候选待核对 | Toast | 重复文件（同 sha256）→ 提示"这份已经在了" |

## 二、CRUD 双通道矩阵（每个可写实体一行）

| 实体 | AI 协助（默认） | 手工（收敛） | 说明与红线 |
| --- | --- | --- | --- |
| `transfusion` 输血 | 拍单/对话 → 日期、输血前 Hb、量、制品、反应 | 「⋯ 更多」5 字段 + 数字键盘 | Hb 只记数值不判高低；"反应"存原文 |
| `iron_lab` 铁蛋白 | 拍化验单 → 日期、数值、单位、参考区间、化验室 | 4 字段 | 参考区间缺失 → `null`，不猜；不画阈值线 |
| `chelation_plan` 方案 | 对话/拍处方 → 药名、剂量原文、途径、起服日、变更原因原文 | 5 字段 | 换药新增行；剂量存**原文文本**，不拆分算 mg/kg |
| `t2star_report` 心肝铁 | 拍报告 → 日期、器官、T2\* 数值、报告原文 | 4 字段 | **不做判读**（无阈值区间、无"正常/异常"） |
| `growth_measure` 生长 | 对话/拍记录 → 日期、身高、体重 | 3 字段 + 数字键盘 | 百分位读取时算；参考标准版本随行显示 |
| `screening_item` 筛查 | 拍报告 → 项目、日期、结果原文 | 3 字段（项目/日期/结果） | 三态：已做/未做/未出报告 |
| `antibody_record` 抗体 | 拍配血单 → 日期、抗体原文、交叉配血原文 | 4 字段 | 只存原文，不转"阴性/阳性"判定 |
| `cost_record` 费用 | 拍发票 → 日期、类别、金额、医保标记 | 4 字段 | 金额存整数分；空 → `null` |
| `question_item` 问题 | 对话起草问题（**预写进输入框，不自动发送**） | 1 字段 | 不得代患者发言；不得含建议语气 |
| `docs` / `candidates` 资料 | 拖入 → 自动登记 + 抽取候选 | 3 字段登记 | 同 sha256 去重；候选拒收零副作用 |
| `profile` 档案 | 拍诊断/基因报告 → 姓名、生日、性别、关系、确诊日、基因型原文 | 「设置 › 病情档案」6 字段 | `relation ∈ {self, caregiver}`；代记必显示徽章 |
| **心理与家庭**（mind 四子页） | **—** （红线：不由 AI 生成感受、不推测情绪） | 自由文本 + 情绪词选择（仅自己可见） | 默认私密，不进 AI 上下文草稿 |
| **生殖与遗传 · 风险解释** | **—** （红线：不生成风险比例与建议） | 只记"医生当时说的原文" | 界面固定一句：具体风险需医生结合基因型解释 |

## 三、门槛红线 IP1–IP10（本项目的验法）

| # | 红线 | 本项目怎么验 |
| --- | --- | --- |
| IP1 | 无已签认路径文档不开 HTML | 本文件 + G1 签认记录（`docs/SIGNOFF.md` 引用本文版本） |
| IP2 | 双向覆盖，孤儿页 = 0 | `scripts/check-hvt.mjs` 穷举 `(view,sub)` 与路径表，出计数 |
| IP3 | 入口逐字一致 | 脚本 diff `src/pages.json` 文案与路径表「入口」列 |
| IP4 | 完成闭环 + 一步回首页 | 无头走查：每条路径断言产物（记录 +1 / 文件生成）与"回到看板"可点 |
| IP5 | AI 默认 + 候选必核 + 拒收零副作用 | 矩阵逐行核对；拒收后库内无变化（单测） |
| IP6 | 手工收敛：每页 ≤1 编辑入口、表单 ≤6 字段、统一「⋯ 更多」 | 脚本统计每页「⋯ 更多」数量与表单字段数 |
| IP7 | 数字输入用键盘组件 | 抽查 Hb / 铁蛋白 / 身高 / 体重 / 金额 5 处 |
| IP8 | 无裸删除；全站 0 处"不可恢复" | `grep -c 不可恢复` = 0；更正后旧版本可查 |
| IP9 | 双通道同源 | 同一实体两通道各写一次，只有一条版本链（单测） |
| IP10 | AI 示例不代替发言 | 每个一级页 ≥1 处示例：点击后输入框有文案、无自动发送 |
