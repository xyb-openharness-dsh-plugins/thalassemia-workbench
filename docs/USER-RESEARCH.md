# USER-RESEARCH · 用户研究证据分层（本轮：0 一手访谈）

> 体例按 starter 21 号（Research Playbook）与 26 号的"证据与假设分开写"。
> 本文件只回答一件事：**哪些结论有证据、哪些是假设**。没有任何一句可以越级。

## 一、证据分层（四层，不许混写）

| 层 | 定义 | 本轮条数 | 能否当"需求已确认" |
| --- | --- | --- | --- |
| E1 一手访谈 | 我/团队与真实患者或家长直接对话的记录 | **0** | 能 |
| E2 公开患者叙述 | 患者/家长在公开渠道的自述原文（附 URL 与抓取日） | **15**（已回源逐字核对，见 `research/patient-voices.md`） | 部分能，但不得写成"我们访谈了" |
| E3 文献与指南 | 可署名、可回溯的出版物（需取得全文或至少可核实书目） | 书目级 1 条（TIF 2021 TDT，PMID 38683909）/ 正文 0 | 能支撑"这是公认说法"，不能支撑"用户需要这个" |
| E4 推导假设 | 由疾病轴与临床流程推导，未经用户确认 | **全部场景句** | **不能** |

**本轮所有患者场景句都是 E4**，界面统一挂「假设句 · 未经访谈核实」徽章；README 与 SPEC 同步声明。

## 二、研究问题（下一轮访谈要回答的 6 个）

| # | 问题 | 为什么要问 | 若答案与假设相反，改什么 |
| --- | --- | --- | --- |
| Q1 | 家长实际用什么在记？（纸质本 / 微信群截图 / 医院 App / Excel） | 决定"导入"还是"从零记" | 若已有纸质本 → 优先做批量补录与拍照导入 |
| Q2 | 输血日前后，最想确认的是哪一件事？ | 决定看板第一张卡 | 若是"下次是哪天" → 倒计时升级为主卡，间隔折线降级 |
| Q3 | 铁蛋白报告出来后，会去查"这个数代表什么"吗？查到什么？ | 决定术语页的写法与是否触发焦虑 | 若会查且查到错误信息 → 术语页提前到一级入口 |
| Q4 | 去铁药漏服/漏打时，会想被记录提醒吗，还是反感被评价？ | 决定打卡形态（记录 vs 评分） | 若反感 → 去掉任何"完成率"表述，只留日历 |
| Q5 | "再生一个"这件事，信息是在医院解决还是要回家自己查？ | 决定生殖与遗传页的存在形态 | 若在医院解决 → 降级为"资料夹 + 问题清单" |
| Q6 | 费用会不会真的有人记？谁来记？ | 决定费用页优先级 | 若没人记 → 降为 P2，只留医保救助入口 |

## 三、已确认的事实（不含推断）

1. 重型地贫需要**长期规律输血**，并需要**去铁治疗**——这是疾病定义层面的共识（E3 书目级：TIF 2021 TDT 指南存在且为第 4 版，ISBN 9789963717187）。
2. 长期输血会带来**铁过载**，需要用药物帮助排铁——同上（E3 书目级）。
3. 中国南方省份（广东、广西、海南、云南等）地贫携带率较高——**E4 推导**（未取得流行病学原始文献，不作数字引用）。
4. 患者与家长在门诊中处于**信息弱势**（说不清治疗史、记不住医嘱）——**E4 推导**，未访谈。

> 第 3、4 条虽"看起来显然"，仍标 E4：**没有出处就不是事实**，这条纪律比结论本身重要。

## 四、抓取失败记录（诚实区）

| 目标 | 尝试 | 结果 |
| --- | --- | --- |
| 中文指南全文（2025 罕见病 #78 / 中华医学会地贫指南） | nhc.gov.cn、cnki | HTTP 412 / 不可达 |
| TIF 指南正文 | NCBI Bookshelf、europepmc.org/books | reCAPTCHA 挑战页 / Cloudflare 403 |
| 公开患者叙述（病友组织、媒体报道） | 搜索引擎 + 站点直连 | 见 `research/patient-voices.md` 失败清单；本轮未取得可引用的患者原话 |
| 通用检索 | DuckDuckGo html 端点 | 超时；cn.bing 返回与查询不匹配的结果，不可作证据 |

**结论**：本轮**没有 E1**（一手访谈 0 条）；**E2 取得 15 条**（正规媒体 14 + 机构官网 1），已按条回源核对。
其中 6 条挂到功能线（见 `docs/FEATURE-LINES.md`），其余 9 条作旁证。任何把 E4 假设写成"患者说"的做法都是伪造，禁止。

### 4.1 E2 的已知缺口（三条，最影响设计）

1. **生育顾虑**：公开原话 0 条 → F06「生殖与遗传」整条功能线仍是纯假设，G2 评审应重点质疑它是否该存在。
2. **校园"被叫地贫儿"**：0 条（仅成人携带者 2.15 可作污名旁证，**不可**代表 TDT 家庭）。
3. **"铁蛋白看不懂"的第一人称表述**：仅 1 条（2.9 以数值方式转述），不足以支撑术语页作为一级入口的强度。
