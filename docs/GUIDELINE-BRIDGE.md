## 五、界面上的三条硬规则（G1/G2 启用后）

1. **两段式**：上栏原文 + `版本 · 页码 · 主题`，下栏"你的记录是…"（只放事实），中间禁止出现"所以/因此/你需要"。
2. **不做判读**：不显示"你的 T2* 属于哪一档"；分档表仅作为**指南原文**存在，用户对照与否自便。
3. **不推算"该查了"**：节奏只算"距上次记录 N 天"与"参考节点"；是否该查由 `screening_item.planned_date`（医嘱原文）决定。
