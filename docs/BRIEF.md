# 需求起点

来源：初始化配置。用户、场景和流程是有效的SPEC互动素材；继承会话中已有明确确认，其余不能仅因配置通过校验就当成设计定稿或研究验证。

目标用户：重型地中海贫血（输血依赖型）患儿家长为主要记录者，兼顾成年患者本人；南方省份家庭为主

场景：每 2–4 周规律输血，需记录输血前血红蛋白与输注量；血清铁蛋白季度复查与去铁方案调整；儿童生长发育与内分泌并发症筛查；同型地贫配偶的生育与遗传咨询准备

核心流程：
1. 选择本机资料目录并导入血常规/铁蛋白/配血报告
2. 核对候选信息，建立确诊与分型档案（基因型原文照抄）
3. 记录输血周期与去铁方案变更
4. 整理铁蛋白与生长发育趋势
5. 生成复诊与遗传咨询准备材料

完成结果：得到来源可追溯、可核对的个人/代记病程档案：分型与基因型档案、输血周期本、去铁方案与依从记录、铁蛋白与生长发育趋势、内分泌筛查日历、复诊与遗传咨询准备材料；所有候选信息经用户核对入档，不提供诊断与治疗建议

初始布局选择：business-first
