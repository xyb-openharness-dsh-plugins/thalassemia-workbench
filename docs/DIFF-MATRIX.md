# DIFF-MATRIX · FerroPal 与家族样板的差异（防"换名复用"）

- 对照对象：**样板基准** `cervical-workbench` v0.1.1（prototypes/v0.2）· **成熟基准** `breast-cancer-workbench` v0.12.0（prototypes/v0.3，26 号口径）
- 本项目：`src/pages.json`（页面树唯一源）
- 实测时间：2026-10-25 · 命令：`node scripts/measure-diff.mjs` · 退出码 0

## 一、重名率实测（脚本算，不手写）

```
对照 cervical（样板基准）（v0.2：12 一级 / 38 二级）
  一级：13 页，重名 6 → 46.2%  [看板、营养与日常、心理与家庭、资料库、病情一图秀、就诊准备]
  二级：45 页，重名 9 → 20%    [资料库、整理草稿 / 核对、病情档案、指标检测、病情汇总、数值曲线、分类与事件、数据口径、复诊节奏]
对照 breast（成熟基准 26 号）（v0.3：8 一级 / 27 二级）
  一级：13 页，重名 6 → 46.2%
  二级：45 页，重名 7 → 15.6%  [资料库、整理草稿 / 核对、病情档案、指标检测、病情汇总、已保留结果、报告与任务]
判定：PASS（阈值 一级重名率 ≤70%）
```

口径：一级重名 = id 或中文 label（去"与/和/·"后）完全一致；二级按 label 比对（二级无 id）。
**刻意保留的 6 个同构页**是家族四核心模块（看板 / 资料库 / 一图秀 / 就诊准备）+ 26 号口径要求的营养、心理两条照护线。
它们保留的是**骨架**，内容全部本癌种化（见 §三）。剩下 7 个一级页是本品类新增，家族内无对应物。

## 二、形态差异：这是 R3「代记型」慢病，不是肿瘤治疗线

| 维度 | 样板 cervical（肿瘤） | 基准 breast（肿瘤 26 号） | FerroPal（TDT） | 证据 |
| --- | --- | --- | --- | --- |
| 记录主体 | 患者本人 | 患者本人 + 照护者 | **家长代记为主**（同一账号"本人/代记"双视角） | BACKLOG §2.3 R3 形态 |
| 时间结构 | 治疗线（手术→放化疗→维持）有终点 | 治疗线 + 术后恢复阶段 | **无终点的周期循环**：输血每 2–4 周 / 铁蛋白每 3 月 / 心铁每年 | 疾病轴 |
| 核心数据 | 分期、SCC-Ag、影像 | 分子分型、治疗线、上肢围度 | **输血前 Hb、输注量、铁蛋白、心肝铁 T2\*、身高体重百分位** | 见 §四 |
| 判读需求 | 有（家族用 CTCAE 对照） | 有 | **无判读**：T2\* 与铁蛋白只记报告原文与数值 | 红线 D8/M1 |
| 生育线 | 生育保留（治疗致不孕） | 生育与哺乳 | **遗传风险 + 同型配偶 + 产前诊断时点**（不是治疗损伤，是遗传概率） | 差异点 3 |
| 费用线 | 多无独立页 | 无独立页 | **独立一级页"费用与血源"**（输血/去铁/医保/血源紧张） | 差异点 6 |
| 终末期 | 有 | 有 | **本轮明确不做** | DEV-REQUIREMENTS §四 |

## 三、差异化矩阵（场景 → 功能 → 怎么验）

| # | 场景（患者视角） | 功能 | 怎么验 |
| --- | --- | --- | --- |
| 1 | 「每次输血前抽血，血红蛋白多少、这次输几个单位，回家就记不清了；医生问'上次输血是哪天'，我只能翻手机相册」 | **输血本**：日期 / 输血前 Hb(g/L) / 输注量（U 或 ml）/ 血制品类型 / 有无反应原文；自动算**间隔天数**（派生值，不落库） | 单测：间隔 = 相邻两次日期差；三态（已输/计划/未记）；无"是否达标"列；`check-schema` 判读列断言 0 命中 |
| 2 | 「铁蛋白单子上的数字忽高忽低，我不知道医生为什么这个月让加药」 | **铁蛋白趋势 + 去铁方案变更线**（药名/剂量/起止/换药原因原文摘录），方案变更以事件标记叠加在趋势上 | 分类事件不进曲线（`kind!=='numeric'` 不进 `smoothPath`）；显式 `null` 不画成 0；方案与铁蛋白同库同源 |
| 3 | 「孩子比同班同学矮一头，青春期也没动静，我不知道该在什么时候查什么」 | **生长发育**：身高/体重/年龄性别百分位（本地算，标注参考标准与版本）+ 内分泌筛查日历（糖代谢/甲状腺/性腺/骨密度，按年龄给"该问什么"） | 百分位算法单测（含边界：P3/P50/P97）；页面只显示百分位与医生原文，不出现"正常/异常" |
| 4 | 「去铁泵要打 8–12 小时，孩子睡着也得打；漏一次没人知道，但铁是真的会堆」 | **依从打卡**（按药按日，泵时长单独记）+ 日历热力图 | 热力图与打卡同源；不出现"依从性差"这类判定词；漏记 ≠ 未做（三态） |
| 5 | 「医生说'再生一个要查配偶基因型'，我回家就忘了要查哪几项、什么时候查」 | **生殖与遗传**：家系草图 + 基因型原文 + 同型配偶风险问题清单 + 产前诊断时点问题清单（纯问题清单，零建议） | 红线扫描：无"建议产前诊断"；清单可导出 Markdown；每条问题带出处（谁在什么场景说的） |
| 6 | 「一个月输血两次加去铁药，自费多少我从来没算清过」 | **费用与血源**：输血费用 / 去铁费用 / 医保与救助 / 血源与异地，按月聚合**不跨项混算** | 聚合单测（同月多笔 → 分项求和）；金额显式 `null` 不参与求和 |
| 7 | 「网上说地贫要补铁，我差点买了三盒铁剂」 | **术语与误解**：核心词表（铁过载/去铁/输血依赖/铁蛋白）+ 常见误解对照（"补铁"❌ 正面处理） | 文案检查：全仓不出现补铁建议；术语卡带出处与版本；`check-wording` 覆盖 |
| 8 | 「孩子在学校被叫'地贫儿'，回来不说话」 | **心理与家庭**：孩子的心情 / 家长的自责与疲惫 / 学校与同伴 / 兄弟姐妹（四条独立子页，代记视角） | 每子页有内容（非空态）；敏感内容默认私密、不进 AI 上下文草稿 |
| 9 | 「报告一叠，复诊时医生只有五分钟」 | **就诊准备**：复诊节奏（按医嘱原文记）+ 就诊问题清单（从各页"想问的"汇总，带出处）+ 已保留结果 + 报告与任务 | 问题清单导出内容与来源页一致；清单条目数 = 各页选中数之和（单测） |
| 10 | 「十年病历在三个医院，每次都要重新讲一遍」 | **资料库 + 病情汇总**：文档、候选核对、档案、指标、汇总五子页（家族同构骨架，字段本癌种化） | 候选核对闭环（AI 产出 → 用户核对 → 入档）；三态；`private` 三出口代码级过滤 |
| 11 | 「他到底是在变好还是变差，我看不出一张图」 | **病情一图秀**：数值曲线（Hb / 铁蛋白 / 身高）+ 分类事件（输血、换药、住院） | SVG `class="chart"`、`smoothPath` 用 Fritsch–Carlson 单调插值、末点 13px 避让、分类只画节点不连线 |
| 12 | 「下一次该查什么、上次查没查，我全靠记」 | **筛查日历**：年度清单 / 内分泌 / 心功能 / 感染与疫苗，四个子页按年龄排 | 节点 = 起点（确诊日或上次）+ k×间隔；`addMonths` 月末夹取单测（1/31+1 月 = 2 月末） |

## 四、刻意不同、且**不许被统一掉**的 4 处

1. **不做治疗线折页**：家族 32 号折叠卡用于"治疗线"（手术→放化疗→维持）。TDT 没有治疗线，
   折叠卡改为**"一次住院 / 一次输血 episode"** 的折叠展开（收起显示 1 行摘要 + 次数）。
   → 评审判据：折叠卡存在且可收/展，但标签不是"治疗线"。
2. **不设分期页**：地贫无 TNM/FIGO 类分期。第 5 个"该查什么"的需求由**筛查日历**承接，不硬造"我的分期"。
3. **不设 CTCAE 分级**：家族 23 号分级模块在 TDT 不适用（无化疗毒性分级场景）。`docs/METRIC-GRADING.md` 写清"本轮不启用及原因"。
4. **富文本原文优先于结构化**：地贫报告（T2\* MRI、基因型）格式极不统一，字段做"原文 + 少量可结构化数值"，
   不为了好看强行拆成 20 个字段。
